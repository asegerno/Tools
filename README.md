## 🛠️ 收錄工具目錄索引 (Directory Index)

本倉庫整理並分類收錄各類常見實用系統工具：

| 目錄名稱 | 類型說明 | 主要用途 |
| :--- | :--- | :--- |
| **[DrWeb CureIt](./DrWeb%20CureIt)** | 應急掃描殺毒 | 離線急救查殺病毒與頑固惡意程式 |
| **[Ipauly Bootice](./Ipauly%20Bootice)** | 引導磁碟管理 | MBR/PBR 引導修復、分區引導記錄調整 |
| **[MBAM / Malwarebytes-org](./MBAM)** | 惡意程式清除 | 查殺流氓軟體、廣告程式與特洛伊木馬 |
| **[Universal Extractor](./Universal%20Extractor)** | 萬能封裝解包 | 提取安裝包（MSI/Inno/NSIS）內置檔案 |
| **[Pswsoft Crark](./Pswsoft%20Crark)** | 密碼恢復輔助 | 壓縮檔案密碼修復與遺失檢測 |
| **[RAR](./RAR)** | 壓縮與打包 | 經典命令列與實用壓縮歸檔程式 |
| **[Network card MAC address modify tool](./Network%20card%20MAC%20address%20modify%20tool)** | 網路適配診斷 | 網卡物理位址（MAC）除錯與切換 |
| **[Windows Tools / Windows](./Windows%20Tools)** | 系統調優輔助 | Windows 各類底層配置與系統診斷輔助工具 |
| **[WinningPC / ajwawa](./WinningPC)** | 軟體實用集合 | 日常系統優化與推薦工具套件 |
